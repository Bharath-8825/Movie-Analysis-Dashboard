# 🎬 Movie Data Analytics Dashboard

An interactive Excel dashboard built to analyze a dataset of 1,000 movies, uncovering trends in revenue, profitability, genre performance, and audience ratings.

## 📊 Overview

The dashboard summarizes key metrics at a glance:
- **Total Movies:** 1,000
- **Total Revenue:** $159.48B
- **Total Profit:** $95.14B
- **Average IMDb Rating:** 7.10

## 🗂️ Workbook Structure

| Sheet | Description |
|---|---|
| **Dashboard** | Visual summary with KPI cards and charts |
| **Movie_Data** | Raw dataset (1,000 rows × 12 columns) |
| **Pivot tables** | Supporting PivotTables powering the charts |

## 📁 Dataset Fields

`Movie_ID`, `Movie_Name`, `Release_Year`, `Genre`, `Country`, `Runtime_Min`, `Budget_Million_USD`, `Revenue_Million_USD`, `IMDb_Rating`, `Studio`, `Profit_Million_USD`, `ROI_%`

## 📈 Key Visualizations

- Movies Released by Year
- Revenue by Genre
- Movie Count by Genre
- Profit Share & Profit by Country
- Average IMDb Rating by Genre
- Movies by Duration & Average IMDb Rating

## 🛠️ Tools Used

- Microsoft Excel (PivotTables, PivotCharts, Dashboard design)

## 🚀 How to Use

1. Download `Movie_Dashboard.xlsx`
2. Open in Excel
3. Explore the **Dashboard** sheet for insights, or drill into **Pivot tables** for underlying calculations
